# Plan & Do - Center of Excellence (CoE) Topology

## 1. The Orchestrator Node (Me)
- Analyzes macro-goals, routes traffic, manages evolution memory.

## 2. The Philosophy & Brand Node
- **`Brand_Philosopher`**: Ensures absolute alignment. Vetoes any features that violate hyper-minimalism or privacy-first policies. Ideates psychological UX.

## 3. Dual-Track Execution Nodes
- **Track A (Frontend)**:
  - `Frontend_Architect`: React/Zustand state, WebSockets.
  - `Chief_Design_Officer`: Framer Motion, Tailwind, SVG Geometries.
- **Track B (Backend)**:
  - `Backend_Architect`: Next.js APIs, Database schemas, Telemetry data pipelines.

## 4. Quality & Compliance Nodes
- **`Accessibility_Expert`**: Injects WCAG ARIA labels and focus states.
- **`QA_Lead`**: Runs Next.js compilers and unit tests for zero-breakage validation.
